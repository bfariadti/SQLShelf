Os scripts são gravados como um arquivo JSON no repositório indicado e carregados em qualquer computador depois de informar o token uma vez. Use um repositório privado só para os dados: a página do SQLShelf é pública.

Como criar o repositório e o token
  1. No GitHub, crie um repositório privado (ex.: sqlshelf-dados) marcando "Add a README".
  2. Vá em Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token.
  3. Em Repository access, escolha "Only select repositories" e selecione o repositório de dados.
  4. Em Permissions, Repository permissions, defina Contents como "Read and write".
  5. Cole o token acima. Ele fica salvo só neste navegador; em outro computador, informe uma vez.
